# 原型模板说明

## 模板用途

这套模板用于快速复制出 `docs/原型站点/` 原型站点，并支持后续持续追加页面。
这里的目录名固定为 `原型站点`，不是业务主题占位符。

## 复制建议

初始化时默认做法：直接复制 `template/prototype/` 下的整套模板文件到目标目录。
不要先手工创建 `index.html`、`main.js`、`menu.js` 再一点点补齐。
如果用户要求直接初始化原型站点，也不要额外引入 superpower 流程、spec 文档或正式前端工程步骤。

复制以下全部文件到目标目录：

```text
index.html
index.css
main.js
menu.js
pages/home.html
pages/empty.html
pages/404.html
pages/_tailwind.js       ← Tailwind CSS 本地副本（仅原型使用）
pages/_list-common.css   ← 列表页统一组件样式
pages/_fa/               ← Font Awesome 6.5.1 本地副本（仅原型使用）
pages/js/                ← 通用 JS 方法库
  proto-toast.js         ← 统一 Toast 提示
  proto-modal.js         ← 统一弹窗控制
  proto-page.js          ← 统一页面切换
  proto-pagination.js    ← 统一分页组件
  proto-table.js         ← 统一表格排序/筛选
  proto-data.js          ← 统一状态/部门映射
  proto-confirm.js       ← 统一确认弹窗（替代 confirm）
```

## 修改优先级

最常改：

- `menu.js`
- `pages/*.html`

谨慎修改：

- `main.js`
- `index.css`

尽量不改主结构：

- `index.html`

## 初始化建议流程

1. 复制整套模板文件到 `docs/原型站点/`
2. 先确认 `index.html`、`index.css`、`main.js`、`menu.js`、`pages/` 是否齐全
3. 优先改 `menu.js`
4. 再新增或替换 `pages/*.html`
5. 最后才按需调整 `main.js` 或 `index.css`

## 新增页面示例

1. 新建 `pages/product-basic.html`
2. 在 `menu.js` 中添加：

```js
{
  key: 'product-basic',
  label: '基础信息',
  file: 'pages/product-basic.html',
  desc: '产品创建基础信息页面'
}
```

3. 如需调整默认页，修改 `defaultPage`

## 新增一级分组示例

```js
{
  key: 'product-create',
  label: '产品创建',
  children: [
    {
      key: 'product-basic',
      label: '基础信息',
      file: 'pages/product-basic.html',
      desc: '产品基础信息'
    }
  ]
}
```

## 页面命名建议

- `xxx-home.html`
- `xxx-list.html`
- `xxx-detail.html`
- `xxx-edit.html`
- `xxx-config.html`
- `xxx-preview.html`

## 常见维护方式

- 调整菜单层级：改 `menu.js`
- 增加页面说明：改 `menu.js` 的 `desc`
- 修改布局外壳：改 `index.html` 或 `index.css`
- 增加站点级通用能力：改 `main.js`
- 调整单页结构：改对应 `pages/*.html`

## 新增页面必须引入

每个 `pages/*.html` 头部需包含（按顺序）：

```html
<link rel="stylesheet" href="_fa/all.min.css">
<link rel="stylesheet" href="_list-common.css">
<script src="_tailwind.js"></script>
<script src="js/proto-toast.js"></script>
<script src="js/proto-modal.js"></script>
<script src="js/proto-page.js"></script>
<script src="js/proto-pagination.js"></script>
<script src="js/proto-table.js"></script>
<script src="js/proto-data.js"></script>
<script src="js/proto-confirm.js"></script>
```

- `_fa/` — Font Awesome 6.5.1 本地副本
- `_tailwind.js` — Tailwind CSS 本地副本，**仅原型页面使用**，正式交付代码不依赖它
- `_list-common.css` — 列表页统一组件样式（表格 `.data-table`、表单 `.form-input/.form-select`、按钮 `.btn-primary/.btn-default`、分页 `.page-item/.pagination`、卡片 `.card`、状态标签 `.status-badge` 等）
- `js/proto-*.js` — 通用 JS 方法，页面不应重复实现：
  - `ProtoToast.success(msg)` / `.error(msg)` / `.info(msg)` — 统一 Toast
  - `ProtoModal.open(id)` / `.close(id)` — 弹窗控制（自动绑定遮罩点击关闭）
  - `ProtoPage.switchTo(pageId)` / `.back(listPageId)` — 页面容器切换
  - `ProtoPagination.render({containerId, total, current, pageSize, onChange})` — 分页渲染
  - `ProtoTable.sort(data, field, direction)` / `.filter(data, filters)` / `.clearInputs(ids)` — 表格排序/筛选
  - `ProtoData.statusText(code)` / `.deptName(code)` — 状态/部门映射
  - `ProtoConfirm.show({title, message, danger, onConfirm, onCancel})` — 确认弹窗，替代原生 `confirm()`
- 页面内部 `<style>` 只写本页专属样式，两个以上页面复用时再上提到 `_list-common.css`
- 不引入 Google Fonts 等无法本地化的外部资源，字体使用系统栈

## 文件关系速记

```text
index.html -> main.js -> menu.js -> iframe -> pages/*.html
index.html -> index.css
pages/*.html -> _list-common.css
pages/*.html -> _tailwind.js
pages/*.html -> js/proto-*.js
```

## 容错页用途

- `pages/empty.html`：没有菜单或默认页不可用时的空态页
- `pages/404.html`：页面 key 不存在时的错误页；在 `http/https` 场景下也可用于页面文件不可达时的回退页
