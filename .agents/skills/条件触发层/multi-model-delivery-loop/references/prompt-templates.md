# 交接提示词模板

以下模板用于在“规划复核角色”和“实现修复角色”之间交接。

使用时，把尖括号占位符替换成当前需求包、模块、步骤和文件信息即可。

## 1. 规划复核角色生成给实现修复角色的实现提示词

```text
你现在负责实现当前需求包中的一个明确步骤，请只围绕本轮范围修改，不要扩大重构。

需求包：<需求包名称>
模块：<模块中文名>（<模块编码>）
步骤编号：<步骤编号>
步骤目标：<本轮目标>
验收口径：<验收口径>
关联文件/目录：<文件或目录列表>
依赖约束：<后端目录、DataSQL、测试、返回结构等约束>
已完成上下文：<已完成内容>
本轮需要你输出：
1. 实际修改了哪些文件
2. 关键实现点
3. 做了哪些验证
4. 还有哪些未解决问题

如果遇到阻塞，不要自行改目标，直接说明阻塞原因和建议。
```

## 2. 规划复核角色生成给实现修复角色的修复提示词

```text
上一轮实现未通过复核，请只修复以下问题，不要重写无关逻辑。

需求包：<需求包名称>
模块：<模块中文名>（<模块编码>）
步骤编号：<步骤编号>
未通过原因：
<问题 1>
<问题 2>

修复建议：
<修复建议 1>
<修复建议 2>

关联文件/目录：<文件或目录列表>
复核口径：修完后应满足 <验收口径>

本轮需要你输出：
1. 修了哪些文件
2. 每个问题如何处理
3. 做了哪些验证
4. 是否还存在剩余风险
```

## 3. 实现修复角色回交给规划复核角色的复核说明模板

```text
当前步骤已完成实现，请按需求包计划进行复核。

需求包：<需求包名称>
模块：<模块中文名>（<模块编码>）
步骤编号：<步骤编号>
本轮修改文件：
<文件列表>

关键实现点：
<实现点摘要>

已执行验证：
<验证动作和结果>

未解决问题 / 已知风险：
<风险说明>

请重点检查：
1. 是否符合需求包计划和模块目标
2. 是否符合目录放置和项目规范
3. 是否需要补测试、留痕或修复
```

## 4. 规划复核角色最终通过后的收尾说明模板

```text

需求包：<需求包名称>
```

## 6. 规划复核角色复核记录模板

```text
请按以下维度输出本轮复核结果，并同步写入 `实现进度.md`：

需求包：<需求包名称>
模块：<模块中文名>（<模块编码>）
步骤编号：<步骤编号>
复核轮次：<第几轮>
复核角色 / 工具：规划复核角色 / <当前工具>
复核范围：<本轮复核范围>

复核结论表：
| 复核项 | 结论 | 说明 |
| --- | --- | --- |
| 需求符合度 | 通过 / 不通过 | <说明> |
| 目录落位 | 通过 / 不通过 | <说明> |
| 验证执行 | 通过 / 不通过 / 部分通过 | <说明> |
| 留痕完整性 | 通过 / 不通过 | <说明> |
| 回归风险 | 无 / 低 / 中 / 高 / 阻塞 | <说明> |

总复核结论：<通过 / 有条件通过 / 不通过 / 阻塞>
问题级别：<无 / 低 / 中 / 高 / 阻塞>
修复要求：<如有>
是否允许进入下一步：<是 / 否>
下一责任角色：<规划复核角色 / 实现修复角色 / 无>
```

## 7. 角色切换提示模板

```text
角色切换提示

当前阶段：<当前阶段> -> <下一阶段>
当前模块：<模块中文名>（<模块编码>）
当前步骤：<步骤编号>
当前责任角色已完成本轮工作。

请切换到 <下一责任角色 / 工具>，并使用以下提示词继续：

<交接提示词正文>

当前轮在这里暂停，等你手动切换角色后再继续。
```

## 8. 用户切换后恢复执行模板

```text
已切换到 <当前责任角色 / 工具>，请根据上一轮的角色切换提示继续当前步骤。
```
