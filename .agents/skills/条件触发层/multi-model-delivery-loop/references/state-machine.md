# 阶段状态机

## 推荐阶段

- `规划中`
  由规划复核角色负责拆步骤、补验收口径、准备交接信息。
- `实现中`
  由实现修复角色负责按既定步骤写代码。
- `待规划复核角色复核`
  实现修复角色已完成本轮实现，等待规划复核角色复核。
- `复核未通过待修复`
  规划复核角色已指出问题，需要切回实现修复角色修复。
- `验证通过待收尾`
  规划复核角色已确认本轮实现通过，但还有记录、测试说明或收尾动作待完成。
- `已完成`
  当前步骤或当前模块已完成，无需继续切换角色。

## 推荐责任切换

- `规划中` -> 当前责任角色：`规划复核角色`；下一责任角色：`实现修复角色`
- `实现中` -> 当前责任角色：`实现修复角色`；下一责任角色：`规划复核角色`
- `待规划复核角色复核` -> 当前责任角色：`规划复核角色`；下一责任角色：根据复核结果决定
- `复核未通过待修复` -> 当前责任角色：`实现修复角色`；下一责任角色：`规划复核角色`
- `验证通过待收尾` -> 当前责任角色：`规划复核角色`
- `已完成` -> 当前责任角色：空

## 推荐切换确认状态

- `无需切换`
- `待用户切换`
- `已切换待继续`

## 推荐验证结果枚举

- `未验证`
- `验证通过`
- `验证未通过`
- `部分验证`
- `无法验证（已说明原因）`
