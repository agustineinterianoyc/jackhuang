# 需求拆分与实现计划模板

本目录提供正式需求开发使用的模板骨架。

这些模板服务于 AI 和工程协作，不直接放在 `docs/需求/` 下，避免和真实业务文档混在一起。

推荐目标结构：

```text
docs/需求/
├── 原始需求/
│   └── <批次目录>/
├── 模块总表.md
├── 需求包/
│   └── <需求包目录>/
│       ├── README.md
│       ├── 实现计划.md
│       ├── 实现进度.md
│       └── 接口清单.md
└── 模块/
    └── <模块中文名>/
        ├── README.md
        ├── 需求实现记录.md
        ├── 需求实现优化调整记录.md
        └── 数据库留痕索引.md
```

## 使用方式

1. 新批次开始前，先在 `docs/需求/原始需求/<批次>/` 下建立输入资料和 `批次说明.md`。
2. 拆模块前，先查 `docs/需求/模块总表.md`，确认是否命中已有模块。
3. 每批需求或每次迭代，在 `docs/需求/需求包/` 下建立独立需求包。
4. 涉及前后端联动时，在需求包下维护 `接口清单.md`，并在计划和进度中关联接口编号。
5. 每个业务模块在 `docs/需求/模块/` 下长期维护，不随需求包重复拆散。
6. 数据库结构和 SQL 以 `code/backend/DataSQL/` 为正式来源，模块目录只做索引。
