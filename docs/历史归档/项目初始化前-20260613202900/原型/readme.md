# 原型输入目录

本目录用于存放作为 AI 正式输入的批次化原型资料。

## 目录职责

- `docs/原型/<批次原型>/`
  作为 `requirement-implementation-tracking` 的正式原型输入目录
- `docs/原型站点/`
  作为 `prototype-page-builder` 产出的原型站点目录，给人预览，不作为正式需求拆分输入根

## 使用规则

1. 原型目录与需求目录按同一批次号配对，例如 `<YYYYMMDD>批次需求` 对应 `<YYYYMMDD>批次原型`。
2. 每个批次目录至少有一份原型说明文档，说明页面、流程、关键交互和与需求包的关系。
3. 如果存在单独的原型站点页面，可在说明文档中引用，但不要把站点壳目录当成正式输入根。
