# 变更记录索引

> 项目级变更事实源。结合 `docs/规范/变更记录规范.md` 使用。

## 文件分工

- `CHANGELOG.md`：项目级时间倒序变更主线
- `规范变更.md`：项目级规范、流程、约束、目录边界等变更
- `架构变更.md`：技术架构、模块边界、技术基线、依赖结构等变更
- `bug修复.md`：跨模块或具有规范级影响的 Bug 修复

## 模板示例

```markdown
## YYYY-MM-DD（时段）

- 变更类别：（规范变更 / 架构变更 / 业务变更 / Bug 修复）
- 变更摘要：
- 影响范围：
- 关联文档：
- 决策原因：
```
