## 2026-06-13（下午）

- 变更类别：架构变更
- 变更摘要：
  1. 后端业务应用模块由 `ai-training-project` 重命名为 `aldemo`，物理目录、`artifactId`、`spring.application.name`、Nacos dataId 同步收敛
  2. 后端 Java 包根由 `com.hzzenith.ai.training` 调整为 `com.hk.demo`
  3. Nacos namespace 由 `ai_drill_project` 调整为 `aldemo`
  4. MySQL 默认数据库名 / 账号 / 密码占位词统一为 `aldemo`
  5. 父 POM 在 `pluginManagement` 中为 `spring-boot-maven-plugin` 配置 `<skip>true</skip>`，业务应用模块 `aldemo/pom.xml` 显式声明覆盖
- 影响范围：`code/backend/pom.xml`、`code/backend/aldemo/`（含 src、resources、pom）、`code/backend/backend-api|core|data/`（包路径与 pom）
- 关联文档：`docs/项目信息/项目初始化信息.md`、`code/backend/AGENTS.md`
- 决策原因：让脚手架真正承载公司培训项目（aldemo）的运行身份，并避免共享模块上误执行 `spring-boot:run` / `repackage`
