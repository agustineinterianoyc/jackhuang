## 6. CHG-007 Bug 修复

| Bug | 影响 | 根因 | 修复方式 |
|-----|------|------|---------|
| 专业反馈保存500 | 反馈数据无法持久化 | `@TableLogic` + `mapper.delete()` 逻辑删除 → `INSERT` 唯一键冲突 | JDBC `ON DUPLICATE KEY UPDATE` |
| selectList 空返回 | 列表查询全部无数据 | MyBatis-Plus 3.5.15 在 Boot4 下批量读不兼容 | FeedbackRepository 改用 JDBC |
| P05 详情页500 | 已审核任务无法查看 | `detail()` 限制仅 PENDING 可查看 | 移除状态检查 |
| P05 列表状态空白 | 提交/审核状态不显示 | VO 缺少 `*Text` 字段 | 补充字段+Service赋值 |

## 7. CHG-008 remark 字段新增

- **需求来源**: 产品经理要求专业反馈增加备注
- **变更**: `ad_opinion_feedback` 新增 `remark VARCHAR(500) NULL`
- **影响范围**:
  - DDL: schema.sql
  - DO: `OpinionFeedbackDO`
  - Request: `DeptFeedbackSaveRequest.FeedbackItem`
  - VO: `DeptFeedbackDetailVO`、`DeptAuditDetailVO`
  - Service: save 写入、detail 返回
  - Repository: JDBC 查询+INSERT 包含 remark
  - 前端: types + 页面
- **验证**: 保存覆盖正常，detail API 正确返回
