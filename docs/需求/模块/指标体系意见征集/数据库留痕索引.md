## 关键约束摘要

- 表前缀统一：`ad_opinion_`
- 主键统一：`BIGINT UNSIGNED AUTO_INCREMENT`
- 状态字段统一：`VARCHAR(32)`，业务枚举常量
- 主状态共 6 个：`DRAFT / WAIT_FILL / FILLING / DEPT_FEEDBACK / DONE / PUBLISHED`
- 所有业务表包含 `deleted_flag` + `created_at` + `updated_at`
- 不创建物理外键，应用层维护一致性
- 字符集 `utf8mb4`，排序规则 `utf8mb4_general_ci`
- 唯一约束统一带 `deleted_flag`
- 时间字段统一 `DATETIME`（精度到秒）
