# 需求实现记录 — 指标体系意见征集

## 1. 模块目标

- 模块中文名：指标体系意见征集
- 模块编码：`opinion`
- 本模块解决的问题：把绩效考核指标体系修订过程从线下流程承接到系统：企管部上传非结构化指标体系附件 → 基层单位填报修改意见 → 基层人资部主任审核 → 专业绩效联络员反馈（含是否采纳）→ 专业部门负责人审核 → 绩效管理员汇总并补充「调整后内容」→ 发布。

## 2. 需求口径

| 功能点 | 需求来源 | 原型来源 | 业务规则 | 验收口径 |
| --- | --- | --- | --- | --- |
| 创建征集（DRAFT） | 需求 §5.1 | `P01-意见征集管理.html` 新增页 | 必填：征集名称、考核周期、征集对象、基层截止时间、专业截止时间、征集模块；最长 100 字符；同年同名唯一 | DRAFT 可改、其他状态不可改；删除仅 DRAFT |
| 开启征集（DRAFT → WAIT_FILL） | 需求 §4.1 节点 20 + §5.1 | `P01` 编辑页「开启征集」按钮 + 二次确认弹窗 | 前置：征集对象与征集模块齐全；触发 `ad_opinion_unit_task` 批量初始化；通知基层 | 状态推进至 `WAIT_FILL`；不可再编辑征集信息 |
| 基层填报（WAIT_FILL → FILLING） | 需求 §4.1 节点 30 + §5.2 | `P02-基层单位意见征集.html` | 5 Tab + 行级添加 / 删除；意见分类 / 意见内容 / 原因说明（260 字上限）；提交先保存 | 提交后只读；状态推进至 SUBMITTED + PENDING（审核） |
| 基层审核（PENDING → PASS / REJECTED） | 需求 §4.1 节点 40 + §5.3 | `P03-基层单位意见征集审核.html` | 通过：审核子状态置 `PASS`；退回：必填原因 ≤260 字，子状态置 `REJECTED`，基层可再填 | Toast 文案「审核成功」/「退回成功」；退回必填原因 |
| 开启专业反馈（FILLING → DEPT_FEEDBACK） | 需求 §4.1 节点 50 + §5.1 | `P01` 汇总页前置按钮 | 前置：全部基层「已审核通过」；初始化 `ad_opinion_dept_task` + `ad_opinion_feedback` 占位 | 状态推进至 `DEPT_FEEDBACK`；基层不可再退回 |
| 专业反馈（PENDING → SUBMITTED） | 需求 §4.1 节点 60 + §5.4 | `P04-专业部门反馈.html` | 是否采纳 toggle + 采纳说明（采纳=是 时必填，260 字） | 提交后只读；toggle 显示禁用态 |
| 专业审核（PENDING → PASS / REJECTED） | 需求 §4.1 节点 70 + §5.5 | `P05-专业部门反馈审核.html` | 通过 / 退回；退回原因必填 | Toast 文案「审核通过！」/「已退回！」 |
| 自动汇总（DEPT_FEEDBACK → DONE） | 需求 §4.1 节点 80 | — | 全部专业「已审核通过」时由后端自动推进；从 `feedback` 初始化 `summary_item` | 状态自动推进至 `DONE` |
| 调整后内容 + 发布（DONE → PUBLISHED） | 需求 §4.1 节点 90、100 + §5.1 | `P01` 汇总发布页 | R01 在汇总页确认采纳并补「调整后内容」（VARCHAR(1000)）；发布前「采纳=是」行的「采纳说明」全部非空；二次确认 | 发布后所有写操作 403；P02 / P05 已发布查看页透出「调整后内容」 |
| 双向退回（绩效管理员退回） | 需求 §4.1 退回路径 | `P01` 进度弹窗 | R01 在 `FILLING` 时退回单个基层（API-110）；在 `DEPT_FEEDBACK` 且未发布时退回单个部门（API-111） | 仅在对应主状态时可触发 |
| 零报送 | 需求 §6.6 | — | 基层截止时间到 → 系统自动空提交 + 自动审核通过 + `auto_zero_report=1` | 与人工提交在状态字段一致；落 `action_log.action='AUTO_ZERO_REPORT'` |
| 一键 / 单条提醒 | 需求 §5.1 + §6.7 | `P01` 进度弹窗 | 5 分钟内同一目标不重复发通知；记 `reminder_log` | 响应返回 `sent` / `skipped`；前端展示 |
| 截止超时（专业方） | 需求 §6.6 | — | 仅提醒，不自动提交（`OpinionDeptDeadlineRemindJob` 每 30 分钟扫描） | 不修改状态 |
| 进度弹窗 | 需求 §5.1 + §6.2 第 20 条 | `P01` 弹窗 | 700px 大弹窗；分页 10/20/50/100；按名称模糊搜索；按提交状态筛选；行级提醒按钮（仅未提交） | 弹窗规范符合需求 6.2 第 20 条 |
| 数据导入 / 导出 | 需求 §5.1 | `P01` 汇总页 + 各详情页 | Excel 单文件；导入二段式（上传得 `fileId` → 解析校验 → 提交） | 导出 Excel 可在 Office 打开 |
