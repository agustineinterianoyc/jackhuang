## 10. 标准复核项

| 复核项 | 通过标准 | 不通过时如何处理 |
| --- | --- | --- |
| 需求符合度 | 当前实现与 `实现计划.md` 中的步骤目标、功能点和验收口径一致 | 记录偏差点，切回实现修复角色修正 |

| 接口覆盖 | 涉及接口的步骤已在 `接口清单.md` 中记录编号、路径、请求响应和状态 | 标记接口缺失或状态不一致，并要求补齐 |
| 目录落位 | 代码、测试、Mapper XML、DataSQL 或模块文档落在正确目录 | 标记错误目录并要求回改 |
| DataSQL覆盖 | 涉及数据库的步骤已补 DataSQL 明细或模块索引 | 标记缺失的 SQL 留痕或索引 |
| 验证执行 | 已完成本轮必要验证，或明确记录未验证原因 | 标记缺失的测试、构建、接口或 SQL 验证 |
