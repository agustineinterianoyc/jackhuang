## 接口契约摘要

- 接口前缀统一：`/api/opinion/`
- 列表查询统一：`POST /list`，请求体含 `page` + `pageSize` ∈ {10,20,50,100}，响应含 `total` + `list`
- 状态推进类接口返回：最新主状态 + 子状态
- 统一响应格式：`ApiResponse<T>` (`{code, message, data}`)
- 二次确认强动作：API-103、104、105、107、204、404、503、504（前端二次确认；后端保证幂等）
- 权限：所有接口在 controller 层校验角色 + 数据范围
- 零报送不暴露外部接口（纯定时任务）
